# kxtan.github.io

Personal website of Kuok Xuen Tan, built with plain HTML, CSS and JavaScript (no build step) and hosted on GitHub Pages.

## Files

- `index.html`: the whole site, including the inline pixel-art desk illustration
- `styles.css`: theme (warm lofi palette, pixel accents, light/dark tokens)
- `script.js`: scroll reveal, active nav link, light/dark toggle
- `favicon.svg`, `apple-touch-icon.png`, `og-image.png`: icons and the share preview image
- `resume.pdf`

## Light / dark mode

The site follows the visitor's system setting until they use the toggle in the nav; their choice is then saved in `localStorage`.

## Local preview

Open `index.html` in a browser. Pushing to `main` publishes to https://kxtan.github.io.
